

We welcome contributions to the **MN Unemployment** project! Please follow these guidelines to ensure smooth collaboration.

## How to Contribute
- Fork the repository.
- Create a new branch for your changes.
- Follow the project's coding standards.
- Commit your changes and push to your fork.
- Open a pull request to the main branch.

## Reporting Issues
- Use the GitHub Issues tab.
- Provide clear steps to reproduce the problem.
- Include screenshots or logs if possible.

## Suggesting Features
- Open a feature request in Issues.
- Explain the benefit and use case.
- Suggest possible implementation ideas.

## Code of Conduct
- Be respectful and inclusive.
- No harassment or discrimination.
- Constructive feedback only.

## Review Process
- Pull requests will be reviewed by maintainers.
- Feedback may be requested before merging.
- Approved changes will be merged into the main branch.
